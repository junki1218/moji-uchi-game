# もじうちゲーム（moji-uchi-game）

知的障害のある子ども向けの、iPad用 文字入力ゲーム（PWA）。
イラストを見て・聞いて、その名前を画面内の50音キーボードで打ちます。

- カテゴリ: もの／きもち／うごき（各20問）
- ひらがな・カタカナ・両方 を設定で切替
- まちがえたキーは入らず、2回まちがえると正しいキーが光る（エラーレス）
