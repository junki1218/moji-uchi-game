## 1. 共通スタイル（全画像）

子ども（知的障害のある児童生徒）が「何の絵か」を一目で言い当てられることが最優先。美しさより判別しやすさ。

| 項目 | 指定 |
|---|---|
| タッチ | **クレイ（粘土）風**。ストップモーション人形のような、やわらかい立体感。指あとがうっすら残る程度の質感 |
| 背景 | **無地のオフホワイト `#FFF7EC`**。模様・影の床・風景なし（透過はしない） |
| 構図 | 主役1つを**中央に大きく**（画面の60〜75%）。正面または斜め45°。切れ・見切れなし |
| 色 | 彩度はやや高め、はっきりした固有色（消防車=赤、バナナ=黄）。**色数は主役で4〜5色まで** |
| 光 | やわらかい正面光。強いハイライトや暗い影は避ける |
| 余計なもの | **文字・数字・ロゴ・記号を一切入れない**。主役以外の小物は、意味を伝えるのに必要なものだけ |
| 怖さ | 牙・血・泣き叫びなど怖い表現は避ける（「いたい」「こわい」も穏やかに） |
| サイズ | **1024×1024 px の PNG**（正方形）。アプリ側でクロコが WebP 512px に変換する |

### プロンプトの型（英語で生成する場合）

```
Claymation style illustration of {主題}, soft handmade clay texture, stop-motion puppet look,
single subject centered and large, plain solid off-white background (#FFF7EC),
bright clear colors, simple shapes, soft front lighting, child-friendly,
no text, no letters, no numbers, no logo
```

ネガティブ（指定できる場合）:
`text, letters, watermark, busy background, scenery, multiple subjects, dark shadows, scary, realistic photo`

## 6. 納品の約束（全タスク共通）

1. 置き場所: `.agent_flow/assets/` 直下（サブフォルダを作らない）
2. `.agent_flow/ASSET_MANIFEST.json` の `assets` に1枚1件で追記:

```json
{
  "id": "mono_01",
  "type": "image",
  "purpose": "問題イラスト もの: りんご",
  "file_path": ".agent_flow/assets/asset_TASK-002_mono_01_ringo.png",
  "dimensions": "1024x1024",
  "created_by": "Antigravity",
  "task_id": "TASK-002",
  "prompt": "（実際に使ったプロンプト）"
}
```

3. **一覧シート**を1枚作る: 生成した全画像をサムネイルで並べ、下に id とひらがなを入れた確認用画像
   → `.agent_flow/artifacts/verify_TASK-00N.png`（これはクロコとユーザーが見るためのもの。文字を入れてよい）
4. `done_TASK-00N.json` と `logs/log_TASK-00N_agy.md` を書く。ログには、
   作り直した画像・判別しにくいと感じた画像（自己申告）を必ず書く

## 7. 受け入れ時にクロコが見るところ

- [ ] 絵の中に文字・数字・ロゴがない
- [ ] 背景が無地 `#FFF7EC`、主役1つが中央に大きい
- [ ] きもち・うごきの人物が基準人物と同じ（髪型・黄色Tシャツ・青ズボン）
- [ ] 単語を知らない人が見ても、表の単語を答えられる（特に きもち）
- [ ] 怖い表現がない
- [ ] 枚数・ファイル名・台帳登録が一致（`agent_flow.py verify` で機械検査）
