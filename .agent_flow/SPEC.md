# SPEC: がっくんのこくご（旧 もじうちゲーム／moji-uchi-game）

- 作成: 2026-09-30 クロコ（グリルミー4ラウンドの回答から）
- 対象: 知的障害のある子ども（特別支援学校・学級）
- 端末: iPad（Safari → ホーム画面に追加）

## 1. ねらい

イラストを見て（聞いて）、その名前を画面内キーボードで1文字ずつ打つ。
「見る/聞く → 文字を探す → 押す → できた」を失敗体験なしで繰り返す。

## 2. 技術（確定）

| 項目 | 決定 |
|---|---|
| 形態 | Webアプリ（PWA）。オフライン動作・ホーム画面追加に対応 |
| 配信 | GitHub Pages（リポジトリは public） |
| 読み上げ | iPadの合成音声（Web Speech API `speechSynthesis`, `ja-JP`） |
| 画像 | クレイ（粘土）風イラスト。Antigravity が生成（`IMAGE_SPEC.md`） |
| 保存 | 設定は端末内（localStorage）。サーバなし |
| 構成案（仮） | Vite + TypeScript（フレームワークなし）＋ vite-plugin-pwa。実装着手時に確定 |

## 3. 画面遷移

```
スタート画面 ─┬─ [ゲームをはじめる] → カテゴリ選択 → 出題×10問 → おわり画面 → スタートへ
              └─ [せってい] → 暗証番号(4桁) → 設定画面
```

### 3.1 スタート画面
- **2026-10-05: アプリ名を「がっくんのこくご」に変更。背景はがっくんの絵（ユーザー提供）。題名は上、ボタンは下の左右（まんなかのがっくんを隠さない）**
- 大きなボタン2つ：「はじめる」「せってい」
- 背景にクレイ風イラスト（文字なし）。タイトル文字はHTMLで描く

### 3.1.1 えほん（2026-10-05 追加）
- **（2026-10-27）「えほん」を押すと本を選ぶ画面。1 くろまる がっくん／2 がっくんと はっちゃん。本は src/main.ts の EHON_BOOKS に足す。どの本も Google スライドを「リンクを知っている全員・閲覧者」にしておく**
- スタート画面の「はじめる」の下に「えほん」。Google スライド「くろまるがっくん_えほん」を、アプリの中で全画面のスライドショー（/embed）で出す。編集画面は出さない
- ネットが必要。つながっていなければ「えほんは インターネットに つないで みてね」
- スライドは「リンクを知っている全員・閲覧者」に共有しておく（ユーザーが設定する）。共有していないと黒い画面になる

### 3.2 カテゴリ選択（子どもが選ぶ）
- 3つの大きな絵ボタン：**もの／きもち／うごき**。下の段に **ぶん／ぶん・きもち**
- 絵＋ラベル文字（ラベルは設定の文字種に従う）

### 3.3 出題画面（1回 = 10問）
- 上部：進捗（●●●○○○○○○○）
- 中央：イラスト。🔊ボタンでいつでも読み上げ直し
- 答えの枠：文字数ぶんのマス（□□□）。打った文字が埋まっていく
- 見本文字：出題モードに応じて表示（下記）
- 下部：50音キーボード
- 出題順：カテゴリ20問からランダムに10問
- 左上の「やめる」→ 確認ダイアログ →「やめる」でスタートへ（誤タップよけ）

### 3.4 出題モード（設定で切替）
| モード | イラスト | 読み上げ | 見本文字 |
|---|---|---|---|
| ① みてうつ（既定） | ○ | ○（出題時に自動） | ○ |
| ② きいてうつ | ○ | ○ | × |
| ③ えだけ | ○ | ×（🔊で任意） | × |

### 3.5 キーボード（50音表）
- 教室の50音表と同じ並び（行ごとに1列、段は あいうえお）。あ行を右端に置くか左端に置くかは、UI試作でユーザーが決める
- **特殊音は専用キーを別段に並べる**（二段階操作なし）
  - 濁音・半濁音：が〜ぽ
  - 小さい文字：ゃゅょっ（ぁぃぅぇぉ は単語に出てこないので置かない）
  - 長音：ー（「けーき」「ぱとかー」など、ひらがなでも使う）
- 文字種は設定に従う：**ひらがな（既定）／カタカナ**
  - 単語はすべてひらがなで表記する。一般にカタカナで書く語（ばす・ぱとかー・ばなな・けーき）もひらがな
  - 「カタカナ」を選んだときだけ、全単語をカタカナに変換して出題し、キーボードもカタカナにする
  - 「両方」モードは作らない（2026-09-30 ユーザー決定）
  - ボタン・題名など UI の文言は、カタカナ設定でもひらがなのまま
- キーは iPad で押しやすい大きさ（目安 最低 56×56pt）

### 3.5.1 キーボードの字の数（2026-10-17 追加）
- 50音表の上（右）に「☰」（2026-10-17 ★ボタンは外した）。押すと 50おん（★★★★）／25おん（★★★）／10おん（★★）／こたえの もじだけ（★）を選ぶメニュー
- 25・10は、答えの字＋ほかの字をまぜて合計その数。出さないキーは場所を空けたまま隠す（50音表の並びは崩さない）。まぜる字は問題ごとに決め、その問題の間は変わらない
- 選んだものは設定（keySet）に保存し、変えるまで次の問題・次の回も同じ。設定画面の「キーボードの字」でも選べる

### 3.6 手書きモード（2026-09-30 追加）
- 入力方法は設定で先生が選ぶ：**キーボード（既定）／てがき**。子どもの画面には切替を出さない
- てがきのときは、50音キーボードの代わりに**文字数ぶんの手書きマス**を出す
- **マスをタップすると大きな手書きパッドが開く**（2026-09-30 変更。小さいマスに直接書かせない）
  - パッドで書いて「とじる」→ 書いた字が縮小してマスに写る。開き直すと続きから書ける
  - 「けしごむ」：いま開いている1文字をまるごと消す
  - 「つぎのじ」：パッドを開いたまま次の文字へ
  - 出題が ① 見本あり のときは、パッドの横にその文字の見本を大きく出す
  - パッドにも薄い十字の補助線
- **正誤の判定はしない。**書き終えたら子どもが「できた」を押す → 花丸 → 次の問題
  - 見本文字の出し方は出題モード（3.4）に従う。①では見本をマスの上に並べて見比べられる
- **手書きの記録**（2026-09-30 追加）：「できた」を押した問題ごとに、書いた字を横に並べた画像（下に単語と日時）を iPad の中に保存
  - 新しい方から **50問分** だけ残し、古いものから消す（MAX_WRITINGS）
  - 何も書いていない問題は保存しない
  - 設定 →「てがきのきろく」で一覧。1件ずつ／ぜんぶ を端末へ書き出し（iPad は共有シート：画像を保存・ファイルに保存）、1件ずつ／ぜんぶ 消せる

- **（2026-10-17）カラーマス**: 書くマス・見本・手書きパッドを4色に塗り分ける（左上 空色・右上 ピンク・左下 黄色・右下 緑）。字のバランス（どの部屋に何が入るか）を覚えやすくする。見本の行も書くマスと同じ大きさのマスにした。ただし見本の「が」はカラーマスにしない（黒い丸に白い字だけ）

### 3.6.2 なぞり（2026-10-17 追加）
- 設定「入力方法」に「なぞり」（キーボード／てがき／なぞり）
- 書き方はてがきと同じ（マスをタップ → 大きなパッド）。ちがいは、マスとパッドの中に、はじめからうすい見本の字（教科書体）があり、それをなぞること。視写の見本の行は出さない。カラーマスは同じ
- 字が見えているので、ヒントボタンは出さない。書いた字は、てがきと同じように記録に残る
- **（2026-10-17）設定「なぞりの見本の太さ」「ペンの太さ」（ほそい／ふつう／ふとい）**。見本はふちを足す／削って太さを変える（フォントによらない）。当たり判定も見本の太さに合わせる。ペンの太さは、てがきにも効く
- **（2026-10-17）なぞれている間（見本の字のふちから少しまでの中を書いている間）、触っているところからキラキラ星が飛び、キラキラ音が鳴る**。はみ出たら止まる。当たり判定は見本の字を太らせて描いた形（TRACE_TOLERANCE）

### 3.6.3 字をマスの真ん中に（2026-10-17）
- 教科書体の字はフォントの作りでマスの中で少し下に出るので、起動時（とフォント読み込み後）に実際の字の形を測り、見本のマスの字を上下の真ん中にそろえる（--kyo-shift）
- うすい字（ヒント・なぞり）と「が」の活字は、canvas で字の形を測って上下左右の真ん中に描く

### 3.6.1 ヒント（2026-10-03 追加）
- 出題画面の右上に「💡 ヒント」。押すと最初の1文字を薄く出す（単語は1回）
- 文は **1回目＝〇〇（名詞）の1文字目、2回目＝●●（うごき）の1文字目**（2026-10-03 変更）。もう打った段は飛ばす
- キーボード: 答えのマスに薄く表示し、その字を打つ番になったらキーを光らせる。打てば消える
- 手書き: マスと手書きパッドに薄く表示し、なぞって書ける（記録画像には入らない）
- どの出題モードでも出す（2026-10-03 変更）。キーボードでは最初の1文字のキーも光らせる

### 3.6.2 ミニゲーム（2026-10-03 追加、10-04 作り直し）
- **問題の前に毎回**、**次の問題の絵と言葉を使った**ミニゲームを1つ遊ぶ。ゴールしたら「できた！」→ 問題へ
- まちがいの言葉は、同じカテゴリのほかの問題から選ぶ
- 手ざわりは「開発材料【質感】」のデモを移植（src/minigames.ts）。効果音は fx.js を移植し、アプリの音量設定を通す
  | 種類 | 元のデモ | やること | ゴール |
  |---|---|---|---|
  | シャボン玉 | 13_シャボン玉 | 上に次の問題の絵。言葉入りの玉が飛んでくる。**正解の玉だけ**タップで割れる（ほかはポヨンと弾むだけ） | 正解を3つ |
  | 錠前 | 10_ラチェットダイヤル（Lv3 の音 1400Hz） | 文字数ぶんのダイヤル（正解＋ほか3字）を▲▼かスワイプで回してそろえる。そろったダイヤルは緑。文の「が」は固定 | 全部そろうと開く |
  | エアホッケー | 17_エアホッケー（Lv3 大理石） | 上に言葉のゴール3つ。絵のパックをはじいて正解のゴールへ。まちがいのゴールは跳ね返る | 正解に入れる |
- グミ・羽根は廃止（2026-10-04 ユーザー決定）。前の版でグミ・羽根だけを選んでいた端末は、全種類を使う
- 🔊 で正解の言葉を読み上げ。① 見本ありのときは錠前の上に正解の言葉を薄く出す
- 20秒たってもゴールしなければ「つぎへ ▶」を出す。直前と同じ種類は続けて出さない
- 設定：ミニゲーム あり（既定）／なし、種類（複数選択。0にはできない）

### 3.7 間違えたとき（キーボードのみ。確定：エラーレス）
- 間違ったキーは**入力されない**。キーが軽く揺れる（音は出さない）
- **同じ文字で2回間違えたら、正しいキーを光らせてヒント**
- 「×」「ざんねん」などの否定表示は出さない

### 3.8 正解したとき
- **（2026-10-05 追加）花丸の前に、答えのマスを1文字ずつ大きくして読み上げる**（大きくする→読む→戻す→次の字）。キーボードは最後の字を打ったとき、手書きは「できた」を押したとき。小さい字は「ちいさい や」、ー は「のばすぼう」と読む。読み上げ中は入力・ヒント・できたを押せない（やめる は押せる）
- 1問ごと：**花丸がポンと出るアニメ**（約1.5秒）→ 次の問題
- 10問おわり：大きな花丸＋スタンプが並ぶアニメ。「おわり」ボタンでスタートへ
- 「せいかい！」音声はなし。音は 3.10 の BGM・ジングルのみ

### 3.8.1 できたあとの読み上げ・🔊 の位置（2026-10-27）
- 1文字ずつ大きくして読んだあとに、**言葉としてもう一度読む**（でんしゃ: で・ん・し・ちいさい や …… でんしゃ。文は「いぬが はしる」、助詞の は は「わ」）。英語も同じ（S, H, I, P …… ship）
- 問題の画面の 🔊 は、日本語も英語も**絵の左**

### 3.9 設定画面
- **（2026-10-17）問題画面・ミニゲーム画面の左上（やめる の右）に ⚙。ミニゲーム中に変えたらミニゲームから出し直す。押すと暗証番号 → 設定のモーダル**（文字・入力方法・出題・あ行・音・文の「が」・キーボードの字・ミニゲーム）。「とじる」で、変えていれば同じ問題を新しい設定で出し直す（ミニゲームはとばす。その問題の入力は最初から）
- 開き方：**4桁の暗証番号**（初期値 1094、設定画面で変更可）
- 項目：
  - 文字種：ひらがな（既定）／カタカナ
  - 入力方法：キーボード（既定）／てがき
  - あ行の位置：右はし（既定。教室の50音表と同じく右上が「あ」）／左はし
  - 出題モード：①②③
  - 暗証番号の変更

### 3.9.1 設定のタブ（2026-10-27）
- 設定は4つのタブ: **共通**（入力方法・出題・キーボードの字・なぞりの見本の太さ・ペンの太さ・おと・音量・ミニゲーム。設定画面では 問題の管理・てがきのきろく・ワークシート・暗証番号 もここ）／**ひらがな カタカナ**（文字・あ行の位置・ぶん・きもちの じょし・文の「が」「は」）／**アルファベット**（えいごの 文字・えいごの こえ）／**線なぞり**（線の見本の太さ・はじめのヒント あり／なし・1回の数 5／10／20）
- 問題中の ⚙ は、いまのモードのタブから開く。設定画面は さいごに開いたタブ

### 3.10 BGM・ジングル（2026-09-30 追加。指示書は曲ごとに別ファイルで作る）
| # | 場面 | 種類 | 長さ | 曲調 |
|---|---|---|---|---|
| BGM-1 | スタート＋カテゴリ選択 | ループ | 60〜90秒 | のんびりぽかぽか（木琴・ウクレレ・軽い手拍子、BPM90前後） |
| BGM-2 | 出題中 | ループ | 60〜90秒 | かすかな環境音楽（メロディほぼなし、やわらかい和音）。読み上げ中は自動で音量を下げる |
| JGL-1 | 1問正解（花丸） | ジングル | 約0.5秒 | 生成しない。ZukeiCollectApp の correctSound() を流用（880→1760Hz の2音） |
| JGL-2 | 10問おわり | ファンファーレ | 約1.7秒 | 生成しない。ZukeiCollectApp の fanfaleSound() を流用（8音の上昇） |

- 暗証番号・設定画面は無音
- 設定に「おと：あり／なし」と音量を追加（聴覚過敏への配慮）

### 3.11 文字の書体（2026-10-04 追加）
- **見本の文字（見本の行・錠前の見本・手書きパッドの見本）とヒントの薄い字は教科書体**
- iPad には教科書体がないので、教科書体に近い **Klee One**（Google Fonts、かなだけ読み込み、端末に保存してオフラインでも使う）。Windows は UD デジタル教科書体を優先
- ボタン・キーボードなどはこれまでどおり丸ゴシック

### 3.12 版の更新（2026-10-04 追加）
- **（2026-10-05）スタート画面を出しているあいだに新しい版が届いたら、その場で切り替える**（開いた直後に届くと、古い版のまま遊び始めてしまっていた）
- 新しい版は待たせておき、**スタート画面に戻ったときに切り替える**（ゲーム中に読み込み直さない）
- 絵は版ごとの印付きのファイル名（src/images → Vite）。古いプログラムと新しい絵が混ざって、絵と問題が食い違うのを防ぐ
- ホーム画面のアプリは1時間ごとに新しい版を確かめる

### 3.13 視写ワークシート（2026-10-04 追加）
- iPad で遊んだあとに鉛筆で書く用。設定 →「ワークシート」→ 問題を選ぶ → **PDFを保存**（iPad は共有シートの「"ファイル"に保存」。2026-10-04 印刷から変更）
- PDF は各ページを 200dpi の画像にして作る（jsPDF。教科書体を端末に持たせなくても同じ見た目）
- 最初は**さいごに遊んだ10問**が選ばれている。カテゴリごとにタップで選び直せる（番号の順に並ぶ）
- **A4 縦1枚に5問**（10問なら2枚）。1問＝絵（34mm）＋見本の行（教科書体）＋書く行（十字の補助線）
- マスは言葉の長さに合わせて自動（最大16mm。書ける幅142mm に収める）
- 文字種は設定（ひらがな／カタカナ）に合わせる。文の「が」も書く行では空けて自分で書く
- 上に「なまえ」「がつ にち」、「みて かこう」

### 3.14 配布用ワークシート（2026-10-04 追加）
- アプリとは別に、ワークシートの時間や自習で使う PDF。もの／うごき／きもち 別、各20問（A4 縦・1枚5問 → 4枚）
- レイアウトはアプリのワークシートと同じ。見本は Windows の UD デジタル教科書体 N-B、見出しは BIZ UDゴシック
- tools/make_worksheets.py で作る → public/worksheets/worksheet_{mono,ugoki,kimochi}.pdf（公開サイトからもダウンロード可）

- **（2026-10-05）ぶん・ぶん・きもち を追加し、5カテゴリ×（ひらがな・カタカナ）＝10本に**。カタカナ版でも文の「が」はひらがなのまま、見本は黒い丸に白い字。見出しは「ワークシート（カテゴリ）」、下に「がっくんの こくご」。Drive の moji-uchi-game/ワークシート/ にも置いた

### 3.15 プリント（2026-10-05 追加）
- **（2026-10-22）オリジナルは、作る前に「しゅるい（みてかく＝視写／なぞる）」「おおきさ（ふつう＝A4たて5問／おおきい＝A4よこ2問）」「マス（じゅうじせん／カラーマス）」を選ぶ**。選んだものは覚えておく。確認画面は PDF と同じページの絵を出し、「PDFを保存」で保存。なぞるは上の行にうすい字（「が」は黒丸のまま）、下の行は自分で書く
- スタート画面の右下に「プリント」（その下が「せってい」）。押すと「ストック」と「オリジナル」を選ぶ
- ストック: 配布用 PDF 10本をカテゴリごとに「ひらがな」「カタカナ」で並べる（押すと PDF が開く。ネットが必要）
- オリジナル: 設定の「ワークシート」と同じ画面（さいごに遊んだ問題で PDF を作る）。暗証番号なしで開ける。「もどる」はプリントへ

### 3.16 アニメーション（2026-10-17 追加）
- 全体: 画面がふわっと出る、ダイアログがぽんと開く、ボタンは押すとむにゅっと縮む
- スタート: 題名の字が1つずつ落ちてきて、そのあとゆっくり波打つ。ボタンが順に飛び出し、「はじめる」は呼吸するようにふくらむ
- カテゴリ: カードが順に出て、絵がふわふわ浮く。ラベルの字が1つずつ出る
- 問題: 絵がぽんと出て、マスが順に落ちてくる、キーボードが下から。打った字のマスがぷるんと跳ねる。〇〇を打ち終えると跳ねる。いまの問題の点が脈打つ。ヒントがときどき揺れる
- ミニゲーム（キネティックタイポグラフィ、src/kinetic.ts）: やることの文が1字ずつ落ちてくる。シャボン玉が割れると中のことばが字ごとに弾け飛び「ぱちん！」。まちがいは「ぽよん」。ホッケーはゴールのことばが弾け、「ゴール！」が上から落ちて弾む。錠前はそろった字が跳ね、開くと「かちゃっ！」。「できた！」は字が順に跳ね続ける
- おわり: 紙ふぶきが降り、「よく がんばったね！」の字が跳ねる
- 端末の「視差効果を減らす（動きを減らす）」が ON のときは、動きを止める（prefers-reduced-motion）
- 入場の動きは終わったあとに transform を残さない（読み上げの拡大などを邪魔しない）

### 4.1 問題の管理（2026-09-30 追加）
- 設定 →「出題する問題を選ぶ・読み込む」で、カテゴリごとに問題を ON/OFF。ON の問題から1回に最大10問（ON が10問未満ならその数）
- ON が0問のカテゴリは、子どものカテゴリ画面で押せない
- **JSON 読み込み**（書き方は docs/QUESTIONS_JSON.md）。読み込むたびに「追加する／入れ替える」を選ぶ
  - カタカナはひらがなに直す。打てない字・11文字以上・不明なカテゴリは取り込まず理由を表示
- **JSON 書き出し**：ON の問題を写真ごと書き出す（iPad は共有シート）。別の iPad でそのまま読める
- **写真**：どの問題にも iPad の写真・カメラ画像を付けられる（512px の正方形に縮小して IndexedDB に保存）
- 単語の追加・編集を画面で行う機能は作らない（JSON で行う）
- 単語は **1〜10文字**（MAX_CHARS）
- カテゴリは もの／きもち／うごき の3つ固定

### 4.2 文モード「ぶん」（2026-10-02 実装）
- カテゴリ画面で もの／きもち／うごき の下に「ぶん」
- 形は「〇〇が●●」だけ。〇〇＝動物・乗り物、●●＝うごきの言葉（動詞）だけ
- 「が」は既定では最初から表示して打たせない。〇〇を打ち終えると〇〇のマスが緑になり正解音（1段目）→ ●●を打って花丸（2段目）
- **設定「文の『が』」：最初から入れておく（既定）／子どもが打つ・書く**（2026-10-04 追加）。打つ設定でも1段目の合図は〇〇の終わりで出す。錠前の「が」のダイヤルも設定に合わせる
- **見本の「が」は黒い丸に白い字**（出題画面・手書きパッド・アプリのワークシート）。打つマスの「が」は通常の表示
- 手書きでも「が」のマスは書かせない（活字で表示、記録画像にも入る）。「つぎのじ」は「が」を飛ばす
- 最初から20文（bun_01〜20）。画像は IMAGE_SPEC_SENTENCE.md（TASK-006）。届くまでは絵文字
- 〇〇・●●は各10文字まで、合わせて12文字まで（MAX_SENTENCE_CHARS）
- JSON は `{"type":"sentence","subject":"…","predicate":"…"}`

### 4.3 文・きもち「ぶん・きもち」（2026-10-05 追加）
- カテゴリ画面の下の段に「ぶん」と並べて「ぶん・きもち」（カテゴリ id `bunkimochi`）
- 形は「〇〇が●●」。〇〇＝登場人物（動物・ともだち・おとこのこ等）、●●＝きもちカテゴリの言葉（うれしい・かなしい・おこる・こまる・びっくり・たのしい・ねむい・いたい）
- 最初から20文（bunkimochi_01〜20）。絵は生成せず、素材ライブラリ（animal school・ClayAnimation）から表情を読んで選んだ（tools/bunkimochi_from_library.py、TASK-008 として台帳に登録）
- **ヒント2回目（●●の頭）で、そのきもちの絵が問題の絵の右下に浮かび上がる**。絵は、きもちカテゴリの同じ言葉の問題の絵（先生が写真を付けていれば写真）。もう〇〇を打ってあれば1回目で出る
- 「が」の扱い・2段階・文字数の上限は「ぶん」と同じ
- **（2026-10-27）助詞を「は」にもできる。設定「ぶん・きもちの じょし」：「が」（既定）／「は」／「が」「は」こうたい**
  - こうたい＝1問ずつ交代（どちらから始めるかは毎回ばらす。プリントは「が」から）。問題の途中の ⚙ で変えたら、その回の残りも出し直す
  - 「は」は **「わ」と読む**。文の読み上げは「うさぎ わ うれしい」、1文字ずつの読み上げでも助詞の位置だけ「わ」
  - 見本の丸：「が」＝黒に白い字、「は」＝ピンク（#F9C9D6。えほん2の はっちゃん の色）に黒い字。ミニゲームのまちがいの言葉も同じ助詞にそろえる
  - オリジナルのプリント（みてかく／なぞる、ふつう／おおきい）も同じ設定に従う。プリントの選ぶ画面にも同じ切り替えの行を出す
  - ストックに「ぶん・きもち『は』」（worksheet_bunkimochi_ha／_ha_kata）を追加。対象は ぶん・きもち だけで、「ぶん」は「が」のまま
- JSON は `{"type":"sentence","category":"ぶん・きもち","subject":"…","predicate":"…"}`（category を省くと「ぶん」）。●●がきもちカテゴリにない言葉なら、浮かび上がる絵は出ない

### 4.4 英語版「えいご」（2026-10-27 追加。グリルミーで決めた）
- 「はじめる」→ **ことばを選ぶ画面**（ひらがな カタカナ／えいご）→ カテゴリ。英語は「もの」「うごき」だけ（「ぶん」は英会話に親しめる形を後日考える。それまでボタンを出さない）
- 問題は src/english.ts。日本語の もの・うごき の絵をそのまま使い（先生の写真も引きつぐ）、**7文字までの英単語**にした。もの14語・うごき18語（20語に足りない分は、7文字をこえる語〈elephant・umbrella・dinosaur・airplane など〉か、意味が合わない絵〈しょうぼうしゃ・ぱとかー・いちご など〉なので入れていない）
- **ミニゲームの前に「いぬ は dog」の画面**。日本語はひらがな、「は」はピンクの丸（4.3 のきまり）、英単語の下にカタカナの読み方。「いぬ わ」（日本語の声）→「dog」（英語の声）と読み、読み終えたら「つぎへ」。この帯はミニゲームと問題のあいだも出したまま
- **英語の声（2026-10-27 iPad で鳴らなかった件）**: 「最初に見つかった英語の声」だと、おもしろ声（Albert・Bubbles など）やダウンロードしていない声を選んで鳴らないことがある。じどうでは Samantha・Alex・Karen・Daniel などふつうに話す声を名前でさがし、なければ声を決めず言語（en-US）だけ渡す。選んだ声が1.5秒たっても読み始めない・失敗したときは、声を決めずに読み直す。設定「えいごの こえ」で声を選べる・「▶ ためす」で聞ける
- **字の名前の読み上げ**は小文字1字を渡す（english.ts の letterName）。大文字 D を渡すと iPad が「Capital D」と読むため（2026-10-27）
- **できたあとの読み上げ**: 1文字ずつ字の名前 → 最後に単語としてもう一度（S, H, I, P …… ship）。問題の画面の 🔊 は絵の左（2026-10-27）
- 説明は日本語、単語は英語の声（en-US）。できたあとの1文字ずつの読み上げは**文字の名前**（D・O・G。大文字で渡すと「ディー」と読む）
- **カタカナの読み方は、英単語が出るところにいつも**（問題の見本の下・帯・プリントの絵の下）
- 字: 設定「えいごの 文字」で こもじ（既定）／おおもじ。フォントは Andika（読み書きを学ぶ人向け。a・g が手書きと同じ形）
- キーボード: **アルファベット表（ABC順、7字ずつ4段）**。字の数（☰）は ぜんぶ／20もじ／10もじ／こたえの もじだけ
- てがき・なぞり: しくみは日本語と同じ。カラーマスの代わりに**4本線**（上から 空色・ピンク・黄色・緑。字をのせる3本目だけ太く）
- **4本線は学校の4線ノートのきまり**（2026-10-27 直し）: 線は同じ間。大文字は1〜3本目、小文字の a・o などは2〜3本目、b・d・h・k・l は1本目まで、g・j・p・q・y は4本目まで。フォントの字はこの比になっていないので、字を「上の出っぱり／x の高さ／下の出っぱり」に切り分けて帯ごとにのばして描く（glyph.ts の drawEnGlyph）。t の上や i の点は l に対する割合のまま
- プリント: オリジナルだけ（ストックは作らない）。選ぶ画面で「ひらがな・カタカナ／えいご」を切り替える。英語は**いつも A4 よこ（ふつう 3問・おおきい 2問）**で、日本語とは別のページ（日本語→英語の順。PDF はページごとに向きを変える）。英語は**左に見本（なぞる字）→ 矢印 → 右に書く行**（2026-10-27。上下に並べると、見本の4本目と書く行の1本目がまぎれるため）。4本線の高さはページの英語の問題でそろえ、いちばん長い単語が入る大きさ。英語のページは絵を少し小さくして線を大きくとる。マスの設定は使わない、字の間はつめる

### 4.5 英語版「アルファベット」（2026-10-27 追加）
