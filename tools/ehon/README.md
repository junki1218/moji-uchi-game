# えほん「くろまる がっくん」の作り方

1さつめ（2026-10-05）の手順をまとめたもの。2さつめ以降も同じ流れで作れる。

## 全体の流れ

```
① 企画書（Notion）   → ② おはなし（場面と文）  → ③ 画像生成指示書
→ ④ 絵を生成（pptx） → ⑤ make_ehon.py で組む   → ⑥ Google スライドに変換
→ ⑦ 共有             → ⑧ アプリの「えほん」につなぐ
```

## 使うもの・見るもの

| もの | 場所 | 何に使う |
|---|---|---|
| 企画書 | Notion「くろまる がっくん｜『が』を たのしく まなぶ おはなし きかくしょ」 | おはなしの型（あるく → であう → 「○○が……」で止める → めくると変化 → さいごはがっくんも主体に）、表記のきまり（ひらがな・カタカナだけ） |
| アプリの問題 | `src/questions.ts`（ぶん bun_01〜20、ぶん・きもち bunkimochi_01〜20） | 絵本の文は**アプリにある文から選ぶ**（読んだ文をそのままアプリで打てるように） |
| がっくんの見た目の正本 | `.agent_flow/assets/gakkun_start_original.jpg`（アプリのスタート画面の絵） | 画像生成の参照画像。黒い手足・手ぶくろなし |
| 相手の見た目 | `.agent_flow/assets/` のアプリの絵（いぬ `asset_TASK-002_mono_02_inu.png` など） | 画像生成の参照画像。アプリと同じ見た目にする |
| 画像生成指示書 | `.agent_flow/IMAGE_SPEC_GAKKUN.md`（Drive の `画像材料/moji-uchi-game/` にも同じもの） | 全体の約束・がっくんのデザイン・1枚ずつの英語プロンプト |
| 組む道具 | `tools/ehon/make_ehon.py` ＋ えほんごとの JSON（1さつめは `gakkun_01.json`） | 絵と文を 16:9 の pptx に組む |

## 手順

### ② おはなしを決める
- 1場面＝2ページ。1ページ目「○○が……」（変化の前。がっくんは となりで わくわく）、2ページ目「○○が ●●する。」（変化した瞬間）
- **がっくんは相手を動かさない・さわらない**（企画書の約束）
- 文はアプリの「ぶん」「ぶん・きもち」から選ぶ。アプリにない文を使うなら、アプリにも足すか決める
- 1ページ目（表紙）はがっくんの紹介

### ③ 画像生成指示書
- `IMAGE_SPEC_GAKKUN.md` をひな形にする。1・2・3・7章（約束・がっくん・相手・合格の目安）はそのまま使える
- 6章のプロンプトを、新しい場面に書きかえる（a＝変化の前、b＝変化のあと。背景と構図は a と b で同じ）
- 新しい相手が出るなら、3章に参照画像（アプリの絵）を足す

### ④ 絵を生成する
- 1さつめは Gemini で生成し、`kuromaru_gakkun_ehon_images.pptx`（1スライドに絵1枚、2〜15枚目）にまとめて Drive に置いた
- 絵の大きさは 1200×896（横長 4:3 くらい）。右下に「Gemini Notebook」の印が入る
- 「が」がくずれた絵は作り直す（濁点2つ・反転なし）

### ⑤ pptx に組む
1. `gakkun_01.json` をコピーして、新しい JSON を作る（例 `gakkun_02.json`）
2. 書きかえるところ
   - `images_pptx`: ④の pptx の場所（G: ドライブのパス）
   - `output`: できあがりのファイル名
   - `pages`: 1ページずつ。絵は `"slide": 何枚目`（④の pptx）か `"image": ファイル`。文は `lines` に `[文, 種類]`
3. 文の書き方
   - 種類: `title`（題名）／`main`（大事な文）／`nar`（地の文）／`snd`（音・オレンジ）／`gap`（空き行。文は空 `""`）
   - **1行は6字くらいまで**で改行する（Google スライドでは字が少し大きく出て、長いと途中で折れる）
   - 文の「が」（格助詞）は `[が]` と書く → 黒地に白い字になる。「がっくん」の「が」は普通に書く
4. 実行

```bash
python tools/ehon/make_ehon.py tools/ehon/gakkun_02.json
```

→ `tools/ehon/build/` に pptx ができる（build/ はリポジトリに入れない）

### ⑥ Google スライドに変換する
1. できた pptx を G: ドライブ（`画像材料/moji-uchi-game/`）にコピーする
2. Chrome で Drive の pptx を開き、**「ファイル → Google スライドとして保存」**
   （Drive のコネクタでは pptx を Google スライドに変換できない。手でやるか、Claude in Chrome でやる）
3. 字の折れ・はみ出しがないか、全ページを見る。フォントは Google スライドで手直ししてよい

### ⑦ 共有
- 右上の「共有」→ 一般的なアクセスを「**リンクを知っている全員**」、役割「**閲覧者**」
  （子どもの iPad は Google にログインしていないので、これがないとアプリで黒い画面になる）

### ⑧ アプリにつなぐ
- いまのアプリは「えほん」ボタン1つで、`src/main.ts` の `EHON_SLIDES_ID` の1冊だけを開く
- 2さつめを出すには、`EHON_SLIDES_ID` を差しかえる（1さつめが見られなくなる）か、
  「えほん」を押したら本を選べるようにアプリを直す
- Google スライドの ID は URL の `/d/` と `/edit` の間

## 2さつめ（たたき・2026-10-22）

- 「がっくんと はっちゃん」。であいから、きもち（うれしい・かなしい・おこる・こまる・びっくり・たのしい）を中心に7場面
- 格助詞は場面ごとに交代: 〔は〕の場面は はっちゃん、〔が〕の場面は がっくんが あいてのそばへ行く
- 文の「は」は `[は]` と書く → ピンク地に黒い字（はっちゃんの色）
- 絵はまだないので、`"placeholder": "絵の説明"` で説明入りの枠を置いている。絵ができたら `"slide"` か `"image"` に置きかえる
- キャラクターシートは `tools/ehon/refs/`（リポジトリには入れない。正本は Drive「画像材料/moji-uchi-game/がっくん絵本用」）
- 文: `tools/ehon/gakkun_02.json`／たたきの pptx: Drive「がっくん絵本用」
