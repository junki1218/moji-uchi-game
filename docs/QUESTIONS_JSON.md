# 問題を JSON で読み込む

設定（暗証番号）→「出題する問題を選ぶ・読み込む」→「JSONを読み込む」で、iPad の「ファイル」から選びます。
読み込むたびに **追加する**（今の問題に足す）か **入れ替える**（読み込んだ問題だけを出題）を選べます。

## 書き方

```json
{
  "format": "moji-uchi-game/questions",
  "version": 1,
  "questions": [
    { "category": "もの", "word": "ぶどう", "emoji": "🍇" }
  ]
}
```

| 項目 | 必須 | 内容 |
|---|---|---|
| `category` | ○ | `もの` `きもち` `うごき`（`mono` `kimochi` `ugoki` でも可） |
| `word` | ○ | 単語。**1〜10文字**。カタカナで書いても、ひらがなに直して取り込む |
| `emoji` | | 写真がないときに出す絵文字（なければ ❔） |
| `image` | | 写真（`data:image/...;base64,...`）。「JSONに書き出す」で作ったファイルには入っている |
| `id` | | 省略可。最初からの60問（`mono_01` など）を指すと、その問題を ON にするだけ |
| `type` | | 省略可（`word`）。文の問題は `sentence`（下） |

## 文（〇〇が●●）の書き方

カテゴリ「ぶん」に入ります（`category` は書かなくてよい）。「が」は最初から画面に出ていて、子どもは 〇〇 → ●● の2段階で打ちます。

```json
{ "type": "sentence", "subject": "うさぎ", "predicate": "たべる", "emoji": "🐇" }
```

| 項目 | 必須 | 内容 |
|---|---|---|
| `subject` | ○ | 〇〇（だれが）。1〜10文字 |
| `predicate` | ○ | ●●（なにをする）。1〜10文字 |

- 〇〇と●●を **合わせて12文字まで**（画面に収めるため）

## 注意

- 打てない字（`ぁぃぅぇぉ` `ゔ` `ゎ` 漢字・英数字など）を含む単語は取り込まず、理由を表示します
- `questions` を省いて、いきなり `[ ... ]` の配列だけでも読めます
- 見本: [questions.sample.json](questions.sample.json)

## 写真
取り込んだ後、問題のカードの「写真」から iPad の写真やカメラの画像を付けられます（最初からの60問にも付けられます）。
「JSONに書き出す」と写真も入るので、別の iPad にそのまま渡せます。
